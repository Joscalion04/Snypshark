# Network Protocols Capturable in Wireshark – Professional Table

| OSI Layer | Protocol | Meaning | Purpose | Function | Transported PDU | How it Works | Threats / Security Controls |
|----------|-----------|--------|--------|---------|----------------|-------------|---------------------------|
| 2 – Data Link | Ethernet | IEEE 802.3 | Frame data with MAC addressing | Encapsulates payload in frames with MAC header, EtherType, CRC | Ethernet frames | Switch forwards based on MAC table | MAC flooding, VLAN hopping / Port security, DAI, 802.1X |
| 2 – Data Link | ARP | Address Resolution Protocol | Resolve IP to MAC | Requests MAC for a given IP | ARP messages | Broadcast request → unicast reply → ARP cache | ARP spoofing / Dynamic ARP Inspection |
| 2 – Data Link | VLAN | IEEE 802.1Q | Logical network segmentation | Adds VLAN tag to Ethernet frames | Tagged frames | Switch adds tag, routers perform inter-VLAN routing | VLAN hopping / ACLs, 802.1X authentication |
| 2 – Data Link | STP/RSTP/MSTP | Spanning Tree Protocol | Prevent loops in redundant switches | Blocks redundant links until needed | BPDU | Root bridge election, active/blocked ports | STP manipulation attacks / Root guard, BPDU guard |
| 2 – Data Link | Wi-Fi MAC | IEEE 802.11 | Wireless medium access control | Manages association, transmission, and collisions | 802.11 frames | Association → authentication → encrypted transmission | Rogue AP, Wi-Fi spoofing / WIPS, WPA3, SSID segmentation |
| 3 – Network | IPv4 | Internet Protocol v4 | Logical addressing and routing | Encapsulates data in packets, defines TTL and addresses | IP packets | Routers consult routing table, decrement TTL | IP spoofing, ICMP floods / uRPF, ACLs, L3 firewalls |
| 3 – Network | IPv6 | Internet Protocol v6 | Replace IPv4, solve address shortage | Simplifies header, autoconfiguration | IPv6 packets | Neighbor Discovery Protocol replaces ARP | ICMPv6 abuse, rogue RA / RA Guard, IPv6 firewall |
| 3 – Network | ICMP / ICMPv6 | Internet Control Message Protocol | Diagnostics and error messages | Reports unreachable, TTL expired, echo requests/replies | ICMP messages | Host/router generates ICMP on network events | ICMP flooding, ping sweeps / Rate limiting, inspection |
| 3 – Network | BGP | Border Gateway Protocol | Exchange routes between AS | Propagates prefixes and policy attributes | BGP messages over TCP/179 | TCP session → UPDATE/KEEPALIVE/NOTIFICATION → route selection | BGP hijacking / RPKI, prefix filtering, monitoring |
| 4 – Transport | TCP | Transmission Control Protocol | Reliable communication | Orders, retransmits, ensures delivery | TCP segments | 3-way handshake, flow/congestion control | SYN flood, RST injection / Stateful firewall, SYN cookies, rate limiting |
| 4 – Transport | UDP | User Datagram Protocol | Fast communication without reliability | Multiplexes by ports, no flow control | UDP datagrams | Encapsulates data with ports and checksum | UDP flood, reflection attacks / ACLs, rate limiting, IDS/IPS |
| 4 – Transport | QUIC | Quick UDP Internet Connections | Fast, secure connections (HTTP/3) | Multiplexes reliable streams over UDP with encryption | Application streams | Encrypted handshake, avoids HOL blocking | IDS evasion / TLS inspection, WAF support |
| 5 – Session | SIP | Session Initiation Protocol | VoIP signaling | Establishes, maintains, terminates calls | SIP messages | INVITE → 100 Trying → 200 OK → ACK → BYE | SIP flooding, call hijacking / TLS, digest authentication |
| 5 – Session | RPC | Remote Procedure Call | Remote calls like local | Serializes parameters, sends, executes, returns result | RPC messages | Marshaling → transmission → execution → unmarshaling | RPC exploits / Firewalls, authentication, logging |
| 6 – Presentation | TLS | Transport Layer Security | Data encryption | Encrypts and authenticates L7 traffic | Application data | Handshake → key exchange → record encryption | Downgrade, Heartbleed / TLS 1.3, PFS, library updates |
| 6 – Presentation | JSON / XML / Protobuf | Data serialization formats | Standardize application communication | Encodes complex structures | Application data | Serialization → transport → deserialization | XXE, JSON injection / Schema validation, secure parsing |
| 7 – Application | HTTP / HTTPS | Hypertext Transfer Protocol / Secure | Web and API exchange | Client-server request-response | HTML, JSON, XML, multimedia | Request → Response, optional TLS | XSS, CSRF, SQLi / WAF, CSP, input validation |
| 7 – Application | DNS / DoH / DoT | Domain Name System / DNS over HTTPS/TLS | Resolve names to IPs | Queries and resolves records | DNS records (A, AAAA, MX, TXT) | Query → recursion → response | Cache poisoning, DNS tunneling / DNSSEC, DoH, DNS firewall |
| 7 – Application | DHCP | Dynamic Host Configuration Protocol | Automatic IP assignment | Assigns IP, mask, gateway, DNS | DHCP messages over UDP 67/68 | Discover → Offer → Request → ACK | Rogue DHCP / DHCP snooping |
| 7 – Application | SSH / Telnet | Secure Shell / Telnet | Remote access | SSH encrypts session; Telnet plain text | Terminal streams | Authentication → interactive session | Brute force, sniffing (Telnet) / MFA, strong keys, disable Telnet |
| 7 – Application | SMTP / IMAP / POP3 | Simple Mail / Internet Mail Protocols | Email | Send, receive, manage emails | Email messages | Client → server → delivery | Phishing, spam / Gateways with SPF/DKIM/DMARC |
| 7 – Application | SNMP | Simple Network Management Protocol | Device monitoring | Queries and controls network parameters | SNMP PDUs and traps | Get/Set, traps | SNMP exploits / Strong community strings, SNMPv3 |
| 7 – Application | NTP / PTP | Network / Precision Time Protocol | Time synchronization | Adjusts host clocks | NTP/PTP messages | Client requests time → server responds | Time spoofing / NTP authentication, IP filters |
| 7 – Application | RADIUS / TACACS+ | Remote Authentication Dial-In User Service | Centralized AAA | Authentication, authorization, accounting | AAA messages | Client → server → response | Credential theft / MFA, encryption, logging |
| 7 – Application | MQTT / AMQP / CoAP | IoT Messaging | Lightweight IoT communication | Publish/subscribe or request-response | Application messages | Broker delivers messages to subscribers | Message spoofing / TLS, authentication, QoS |
| 7 – Application | RTP / SRTP | Real-time Transport Protocol | Audio/video streaming | Real-time media transmission | RTP packets | Sender → network → receiver | Media hijacking, eavesdropping / SRTP encryption, authentication |
| 7 – Application | Kerberos | Key Distribution Center | Centralized authentication | Ticket granting for services | Encrypted tickets | AS → TGT → ST → Service | Ticket theft / Synchronized clocks, strong encryption |
| 7 – Application | LDAP | Lightweight Directory Access Protocol | Directory management | Query and modify directory entries | Directory entries | Client → server → response | LDAP injection / TLS, access control |
| 7 – Application | OAuth2 / OpenID Connect | Authorization / Authentication | Identity delegation | Token-based access | JWT / tokens | Authorization code flow, token introspection | Token theft / HTTPS, refresh token, scopes |
